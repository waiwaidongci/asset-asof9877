# 社区工具借还期末在管率台账

按交接日还原工具去向，核对月末有效资产与在管数量。

桂桥社区工具共享站，由两名值班员和四名志愿者为周边三个小区办理工具借还。 值班员从纸质交接簿整理接收、借出、归还和退役事件。站务协调员按月核对实物、跨月未归还工具及退役登记，复核后将台账交给居委会资产管理员。

- 当前库存表被归还记录覆盖，月底补做上月台账时查不到当时的借出状态。
- 换班重传交接单后，同一笔借出或归还可能被重复计数。
- 月末存量被累计求和，已退役工具有时还留在在管率分母里。

## 业务模块

| 模块 | 用途 |
|---|---|
| 值班总览 | 查阅业务口径、当班流程及最新运行。主管可以核对审计记录。 |
| 交接事件 | 下载「桂桥工具流转_20261121.csv」并核对字段。分析员可导入 UTF-8 CSV，保留数据指纹和原始行。 |
| 期末盘点 | 选择批次和参数并提交后台计算，可从运行列表追踪状态。 |
| 快照与月度勾稽 | 查看业务指标、证据表和解释，通过来源链接回查数据。 |
| 台账复核 | 查看待处理或已完成记录。复核主管可提交台账复核及依据。 |
| 盘点报告交付 | 按批查找结果，核对复核状态并下载相应的 CSV。 |

## 启动

```bash
cp -n .env.example .env
docker compose config --quiet
docker compose up -d --build --wait
docker compose exec -T backend python -m scripts.seed_demo
```

浏览器访问 `http://127.0.0.1:18280`。FastAPI 文档位于 `http://127.0.0.1:19280/docs`，PostgreSQL 16 的本地端口为 `17780`。本批在带空格和中文的工作区验证启动。

## 演示流程

1. 11 月 21 日 09:10，值班员将桂桥工具交接簿整理为「桂桥工具流转_20261121.csv」。
2. 在「交接事件」导入 CSV，核对重复上传的 10 月 31 日 GQ-03 借出事件，以及 GQ-02 同日借还的顺序号。
3. 在「期末盘点」设定 9 月 1 日至 11 月 20 日，运行后核对期末 4 件有效工具中有 2 件在管。
4. 在「快照与月度勾稽」核对 10 月末 3 件有效资产，查到 GQ-02 已退役、GQ-03 当时仍在借出。
5. 将截止日改为 11 月 21 日重跑，核对 GQ-01 归还、GQ-06 接收后有 5 件有效工具、4 件在管。
6. 在「台账复核」登记 GQ-04 的追还安排，在「盘点报告交付」导出已复核的勾稽结果。

## 计算口径

- 事件编号一致且业务字段相同的记录只回放一次。同编号内容冲突，或同一工具在同一天重复使用顺序号时，提示修正。
- 按业务日期及同日顺序号回放。接收后进入在管，借出和归还在在管与借出间切换；在管工具可退役，退役终止该资产编号的生命周期。
- 截止日含当日全部事件。在管率为在管件数除以有效资产件数；有效资产包括在管和借出。无有效资产时在管率留空。
- 期初取首日之前的状态。逐月展示自然月末盘点，截止日早于当月末时另列该日日终快照；整段期末取最后一张快照。
- 有效期末＝有效期初＋接收−退役，在管期末＝在管期初＋接收＋归还−借出−退役。事件流量可以按月累计，快照存量与比率按截止日期取值。

## 本地开发

| 组件 | 实现 |
|---|---|
| 前端 | Nginx 与原生 HTML、CSS、JavaScript。`frontend/src/pages` 放页面，`components/common` 放共用表格、图表及表单。 |
| API | Python 3.11、FastAPI、SQLAlchemy。`backend/src/domain` 放本项目字段、业务计算和演示数据，`routes` 放接口，`models` 放表模型。 |
| 后台 | 独立 Python worker，通过 Redis 唤醒，从数据库租约领取计算，CSV 写入共享卷。 |
| 数据 | PostgreSQL 16 存储批次、运行与审计。`backend/scripts/seed_demo.py` 可安全重复执行。 |

改动前端后执行 `docker compose up -d --build frontend`。改动接口或算法后执行 `docker compose up -d --build backend worker`，再刷新浏览器。如需保留数据，停止时执行 `docker compose down`。使用 `docker compose down -v --remove-orphans` 会清除该项目的数据库、Redis 和报表卷。

`.env.example` 中的 `COMPOSE_PROJECT_NAME`、`FRONTEND_PORT`、`BACKEND_PORT`、`DB_PORT`、`APP_SUBNET` 控制项目隔离。`DB_PASSWORD`、`JWT_SECRET` 和 `SEED_DEMO` 为本机演示默认设置。后端 `constants/enums.py` 与前端 `src/constants/enums.js` 保持角色、运行状态和复核状态一致。项目许可证见 `LICENSE`。
